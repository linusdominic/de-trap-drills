# Your profile (template)

Copy this file to `private/profile.md` and fill it in. `private/` is git-ignored, so it stays on your machine. Coach mode reads it for behavioural practice and will not invent anything that is not written here.

## Roles

- **Current role:** title, company type, dates, team size.
  - A project: what it was, the scale (rows, GB, jobs, people), and one measured result.
  - Another project, with its numbers.
- **Previous role:** the same shape.

## Skills

Languages, engines, orchestration, clouds. Only what you could answer a follow-up question about.

## Gaps to watch

What a sceptical interviewer would probe: years of experience, tools you have not used, stories you do not have yet.

## Stories

One line per story, mapped to what it shows. Add real numbers and dates; where you have none, describe the before and after in words.

| What it shows | The story | Details you must be able to give |
| --- | --- | --- |
| Leading a large technical change | | How you planned it, what ran in parallel, what you would do differently |
| Finding a problem nobody else saw | | How you found it, who it affected, how you proved it |
| Raising the team's standards | | The rule you set, how you got agreement, how you measured adoption |
| Handling an incident | | Detection, impact, fix, and the change that stopped it recurring |
| Disagreeing with a stakeholder | | The evidence you used, the compromise, committing once decided |
| Working through ambiguity | | How you defined the terms and got agreement on them |
| Making something much faster | | How you measured before and after |
